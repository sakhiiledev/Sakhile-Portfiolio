# Sakhile Ndlovu — Portfolio

Personal portfolio: systems developer & network engineer, Pretoria.

Plain HTML, CSS and JavaScript — no build step. Deployed on Vercel.

- `index.html` — page structure and copy
- `app.js` — project data (edit the `P` list to add work), filters, drawer, motion
- `styles.css` — design tokens and components
- `assets/icons.js` — technology icons (from Simple Icons, CC0)
- `assets/work/` — project screenshots (1208 × 623 webp)

Run locally: `python3 -m http.server 8000`
